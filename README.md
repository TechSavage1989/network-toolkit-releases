# James Network Toolkit releases

This repository distributes compiled Windows application updates. It does not contain the application's source code.

Use the application's update controls to check for, download, verify, and install the latest release. Release assets include a binary-only Update ZIP and SHA256SUMS for integrity verification.

GitHub's automatically generated “Source code” archives contain only this release repository's distribution files. They are not application update packages.

Third-party notices are included in the Update ZIP. Downloaded executables may be unsigned; only install downloads you trust.
